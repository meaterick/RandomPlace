# RandomPlace

어디로 갈지 정하기 어려울 때, 조건을 고르고 장소를 뽑는 독립 웹사이트입니다. Guestnote의 랜덤 여행 기능을 출발점으로 삼아 디자인, 설정, 추첨, 결과 탐색 흐름을 다시 구성했습니다. 방명록·로그인·계정·데이터베이스는 포함하지 않습니다.

## 사용 흐름

1. **해외 / 국내 / 경기도 / 서울** 중 범위를 선택합니다.
2. 원하는 지역과 세부 조건을 고르고 현재 후보 수를 확인합니다.
3. **1곳 또는 서로 다른 3곳**을 뽑습니다. 지도 위 표시가 후보 사이를 빠르게 옮겨 다니다가 점점 느려지며 결과에 멈춥니다.
4. 결과의 지역명과 좌표를 확인하고 지도 열기, 좌표 복사, 저장 또는 다시 뽑기를 사용합니다.

설정, 최근 결과, 저장한 장소는 브라우저의 로컬 저장소에 보관합니다. 다른 기기와 동기화하지 않으며, 사이트 데이터를 지우면 함께 삭제됩니다. 저장 공간을 사용할 수 없는 브라우저에서도 현재 화면의 추첨은 사용할 수 있습니다.

## 범위와 세부 설정

| 범위 | 후보와 설정 |
| --- | --- |
| 해외 | 68개국 489개 도시(유명 도시 220곳 + 대륙 본토 여행 도시 269곳)에서 대륙·국가를 선택합니다. 아프리카와 섬은 제외합니다. |
| 국내 | 229개 시·군·구 대표점, 16개 시도의 여행 명소 400곳, 서울 장소 280곳에서 시도, 장소 종류(명소만·대표점만·명소 분류), 시·군 구분, 섬 포함 여부를 조절합니다. |
| 경기도 | 31개 시·군 대표점과 경기도 여행 명소 88곳에서 시·군, 장소 종류, 시·군 구분을 조절합니다. |
| 서울 | 25개 자치구에 걸친 280곳의 편집 선정 여행 장소에서 자치구와 장소 종류(궁궐·역사, 공원·숲, 산·전망, 한강·물길, 거리·동네, 시장·먹거리, 박물관·전시, 랜드마크)를 고릅니다. |

공통 설정은 뽑는 개수 **1곳 / 3곳**, **최근 20번의 추첨 결과 제외**, 연출 **시스템 설정 따르기 / 짧게 / 즉시 결과**입니다. 연출이 켜져 있으면 후보 사이를 빠르게 지나가다가(해외는 경보 확인이 끝날 때까지 계속) 결과마다 점점 느려지며 멈추고 번호 핀을 남깁니다. 기기의 동작 줄이기 설정을 따르면 연출 없이 바로 결과를 보여 줍니다. 선택한 조건에서 후보가 없으면 조건을 바꾼 뒤 추첨합니다. 여러 곳을 뽑을 때 같은 추첨 안에서 결과를 중복하지 않습니다.

해외의 아프리카·섬 제외는 고정 규칙입니다. 호주는 대륙 본토만 포함하며, 일본·영국·대만·뉴질랜드와 제주·하와이·시칠리아 등 섬에 놓인 원본 좌표는 해외 후보에서 제외합니다. 국내의 **섬 포함**은 별도의 설정으로, 기본값은 꺼짐입니다. 섬 구분은 카탈로그의 행정구역 분류에 따르고, 명소는 속한 시·군·구 분류를 따르되 섬 이름의 명소(대부도·제부도·선유도·오동도 등)는 섬으로 봅니다. 이 분류는 도시 내부의 모든 작은 섬이나 실제 방문 가능성을 판정하는 기능은 아닙니다.

## 해외 여행경보 확인

해외 결과는 뽑는 시점에 [한국 외교부 해외안전여행](https://www.0404.go.kr/)의 공개 여행경보 지도에서 좌표별로 확인합니다.

- 행정구역 레이어, 경보구역 레이어, 특별구역 레이어를 함께 확인합니다.
- **여행경보 미발령(0단계에 해당하는 표시) 또는 1단계**만 결과로 확정합니다.
- 2~4단계, 특별여행주의보, 알 수 없는 코드, 국가 불일치, 포함 여부 미확인, 불완전하거나 실패한 응답은 확정하지 않습니다.
- 경보 조회에 실패하면 임의의 도시나 과거 확인 값으로 대체하지 않습니다.
- 결과에는 확인한 경보 단계와 확인 시각을 표시합니다.

이는 확인 시각의 **여행 후보**를 고르는 기준입니다. 비자·입국 조건, 교통편, 현지 접근성, 영업 여부나 여행 안전을 보장하지 않습니다. 출발 전 공식 경보와 개별 조건을 다시 확인해야 합니다. 국내·경기도·서울에는 해외 여행경보 조회를 적용하지 않습니다.

## 데이터와 출처

### 해외 도시·세계 지도

원본은 [Guestnote](https://github.com/meaterick/Guestnote)의 유명 도시 234곳 편집 카탈로그와 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) 지도·도시 자료입니다. 한국 도시를 제외한 원본 해외 후보는 220곳입니다. 여기에 `scripts/build-overseas-additions.mjs`에서 대륙 본토의 여행 도시 269곳을 더 편집 선정해 합쳤습니다(`addedBy: randomplace`). 추가 도시는 세계 지도에서 적어 둔 국가 경계 안(해안 도시는 25km 이내)에 있고 다른 나라와 맞닿은 본토 조각이거나 대륙 규모 땅이어야 하며, 섬 조각에 놓이면 빌드가 실패합니다. Natural Earth 자료는 public domain입니다. 유명 도시 목록은 공식 인기 순위나 세계 모든 유명 도시를 망라한 전수 목록이 아닙니다. 대륙 본토 여부는 Natural Earth의 상세 육지 경계를 바탕으로 판정한 원본 분류를 사용합니다.

### 국내·경기도

[통계청 SGIS 2018 / southkorea-maps](https://github.com/southkorea/southkorea-maps/tree/60c8c0cf0016381d80004d6b125760d6c5cb0605/kostat/2018/json)의 행정구역 자료를 가공했습니다. 원자료는 **공공누리 제1유형(출처표시)**입니다. 시의 여러 구를 묶어 시·군 단위의 대표 지역으로 구성하고, 경기도는 31개 시·군을 포함합니다.

여행 명소는 `scripts/build-korea-spots.mjs`에 시도별로 편집 선정한 목록(이름, 시·군·구, 분류, 좌표, 한 줄 소개)이며, 좌표가 적어 둔 시·군·구 경계 밖에 있으면 빌드가 실패합니다(해안·섬은 4km 이내 허용). 서울 범위의 장소도 국내 범위에서 서울특별시 명소로 함께 뽑힙니다.

```sh
node scripts/build-korea-spots.mjs skorea-municipalities-2018-topo-simple.json
node scripts/build-overseas-additions.mjs
```

시·군·구 대표점의 좌표는 해당 지역의 경계 안에서 고른 **대표 지점**입니다. 관광시설이나 방문 가능한 특정 POI의 위치가 아니며, 2018년 행정경계이므로 현재의 경계·명칭과 다를 수 있습니다. 상세 지도에서 실제 목적지와 접근 가능한 장소를 확인하세요.

### 서울

`scripts/build-seoul.mjs`에 편집 선정한 장소 목록(이름, 자치구, 분류, 좌표, 한 줄 소개)이 있습니다. 공식 순위나 전수 목록이 아니며, 좌표는 대표 지점의 근사값입니다. 지도와 자치구 검증에는 [통계청 SGIS 2018 / southkorea-maps](https://github.com/southkorea/southkorea-maps/tree/60c8c0cf0016381d80004d6b125760d6c5cb0605/kostat/2018/json)의 시군구 경계(공공누리 제1유형)를 사용하며, 좌표가 적어 둔 자치구 경계 밖에 있으면 빌드가 실패합니다. 장소를 추가·수정한 뒤 다음처럼 다시 생성합니다.

```sh
node scripts/build-seoul.mjs skorea-municipalities-2018-topo-simple.json
```

운영 시간·휴무·입장 조건은 반영하지 않으므로 방문 전 확인해야 합니다.

### 여행경보

외교부 공개 ArcGIS 여행경보 서비스를 브라우저에서 직접 조회합니다. API 키와 인증 쿠키를 사용하지 않으며, 브라우저의 현재 위치 권한도 요청하지 않습니다. API의 경보 코드나 응답 구조가 바뀌면 미확인 상태로 처리하고 매핑을 점검해야 합니다.

## 로컬 개발과 검증

Node.js 24를 사용합니다. 별도의 백엔드나 Firebase 설정은 필요하지 않습니다.

```sh
npm ci
npm test
npm run dev
```

개발 서버가 출력하는 로컬 주소를 브라우저에서 엽니다. 정적 웹사이트이므로 빌드 산출물을 생성하는 별도 단계는 없습니다.

브라우저 검증을 실행하려면 Playwright의 Chromium을 설치합니다.

```sh
npx playwright install chromium
npm run test:browser
```

단위 테스트는 데이터 범위와 추첨·설정·여행경보 판정을 확인하고, 브라우저 테스트는 범위 전환, 조건 조절, 결과 동작과 반응형 화면을 확인합니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다. 이후 `main`에 올리거나 `GitHub Pages` 워크플로를 직접 실행하면 다음 순서로 진행합니다.

1. Node.js 24에서 `npm ci`와 `npm test` 실행
2. 테스트 성공 후 `public/` 업로드
3. GitHub Pages 배포

기본 주소는 [meaterick.github.io/RandomPlace/](https://meaterick.github.io/RandomPlace/)입니다. 경로가 있는 Pages 주소에서도 동작하도록 상대 경로로 정적 파일을 불러옵니다. 웹페이지에서 사용하는 공개 경보 서버 연결은 CSP에서 해당 호스트만 허용합니다.
